# T03 - Logging infrastructure

**Status:** `todo`
**Owner:** `backend-coder`
**Dependencies:** `[T01]`
**Contracts:** `[CONTRACT-LOG-001]`

## Description
Add `logback.xml` as the SLF4J backend plus a mask-before-write filter so secrets never reach log output, and expose the `kotlin-logging` facade from the `infra.logging` package (design §2).

## Acceptance Criteria
- [ ] `src/main/resources/logback.xml` is the app's SLF4J configuration (console appender, INFO default for app packages) and is picked up automatically — no programmatic logback configuration in code.
- [ ] Mask rules cover `DEEPSEEK_API_KEY`, `DB_PASSWORD`, `Authorization` (including `Bearer`), and JSON fields `api_key` / `password` / `secret` / `token` (design §2); a unit test logs a fake secret of each kind and asserts the masked form appears in the output while the plaintext never does.
- [ ] Masking is a logback filter applied to every appender: a test writing through SLF4J (not a logger constructed directly) proves the masked output (design §3: credentials and secrets never appear in logs).
- [ ] Main code logs via `kotlin-logging` only: `grep -rn "println" src/main` returns nothing.
- [ ] `./gradlew build ktlintCheck detekt` completes with 0 errors.

## Artifact
- `src/main/resources/logback.xml`
- `src/main/kotlin/.../infra/logging/` (mask filter, logger setup)
