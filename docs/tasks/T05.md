# T05 - CI & linting setup (both repos)

**Status:** `todo`
**Owner:** `git-reviewer / code-style-reviewer`
**Dependencies:** `[T01, T04]`

## Description
Add linting and CI to both repos on the foundation code: detekt + ktlint for the Kotlin backend, ESLint flat config + Prettier for the frontend (D-4, design §5), and GitHub Actions workflows that run build + lint on `main`, so `usual` / `alternative` inherit a clean gate at fork time.

## Acceptance Criteria
- [ ] Backend: `detekt.yml` at the repo root; `./gradlew detekt ktlintCheck` completes with 0 errors on the T01–T03 code.
- [ ] Frontend: ESLint flat config (`eslint.config.js` with typescript-eslint + react-hooks + `eslint-config-prettier`); `pnpm lint` and `pnpm format` complete with 0 errors on the T04 code.
- [ ] Backend `.github/workflows/ci.yml` runs the Gradle build + lint on push/PR to `main`.
- [ ] Frontend `.github/workflows/ci.yml` runs `pnpm install` + lint + build on push/PR to `main`.
- [ ] Lint/CI configuration is branch-shared: it lands on `main` before the `usual` / `alternative` fork (design §7).

## Artifact
- backend: `.github/workflows/ci.yml`, `detekt.yml`
- frontend: `.github/workflows/ci.yml`, `eslint.config.js`
