# T10 - CI workflows

**Status:** `done`
**Owner:** `git-reviewer`
**Dependencies:** `[T01, T07]`
**Contracts:** `[]`

## Description
Add GitHub Actions CI to both repos — build + lint on push/PR to `main` — landing before the `first`/`second` fork so both branches inherit a clean gate (design §7).

## Acceptance Criteria
- [ ] Backend `.github/workflows/ci.yml` triggers on push and PR to `main` and runs `./gradlew build detekt ktlintCheck` on a JDK 17+ runner; it provides the local Postgres (service container `postgres:15-alpine` on 25432 + schema/seed step) so the DB-backed tests from T05/T06 run; the workflow completes green against the T01–T06 code.
- [ ] Frontend `.github/workflows/ci.yml` triggers on push and PR to `main` and runs `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm build`; it completes green against the T07–T09 code.
- [ ] Both workflows gate only `main` (branch filters) and contain no secrets — no API keys or credentials in the workflow files.
- [ ] CI configuration is committed on `main` before the `first`/`second` fork (design §7), so both branches inherit identical gates.

## Artifact
- backend: `.github/workflows/ci.yml`
- frontend: `.github/workflows/ci.yml`
