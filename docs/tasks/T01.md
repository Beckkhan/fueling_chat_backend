## Description
Create the Kotlin/Ktor backend build on the frozen stack — JDK 17+ toolchain, Kotlin 2.x, Ktor (netty, content-negotiation, kotlinx-json), Kodein DI, Koog `ai.koog:koog-agents-jvm:1.3.0` (D-16), Exposed + HikariCP, kotlinx-serialization, SLF4J + logback, JUnit 5 / MockK (spec §8) — with ktlint, detekt and a repo-root `.editorconfig`, so every later backend task inherits a green build+lint gate.

## Acceptance Criteria
- [ ] `./gradlew build` completes with 0 errors on the JDK 17+ toolchain declared in `build.gradle.kts`; `gradle/wrapper/` is committed and `./gradlew --version` works with no system Gradle install.
- [ ] `./gradlew ktlintCheck` completes with 0 errors and `./gradlew detekt` completes with 0 issues; both are wired into the default `check` lifecycle (`./gradlew check` runs them).
- [ ] `build.gradle.kts` pins the frozen stack: Kotlin 2.x, Ktor (netty, content-negotiation, kotlinx-json), Kodein DI, Koog `ai.koog:koog-agents-jvm:1.3.0` (D-16), Exposed + HikariCP, kotlinx-serialization, SLF4J + logback, JUnit 5 + MockK (spec §8 backend README contract).
- [ ] `detekt.yml` exists at the repo root with no baseline file suppressing issues; `.editorconfig` exists and ktlint passes with zero `.editorconfig`/ktlint rule conflicts and zero per-file suppressions.
- [ ] `.gitignore` ignores `.env`, `build/`, `data/`, `.gradle/` and IDEA files; `.env.example` remains the only tracked env file (design §6).
