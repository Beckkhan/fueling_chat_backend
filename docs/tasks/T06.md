# T06 - Tool definition & handler

**Status:** `done`
**Owner:** `backend-coder`
**Dependencies:** `[T05]`
**Contracts:** `[CONTRACT-TOOL-001]`

## Description
Add `resources/tools/get_fueling_info.json` byte-identical to CONTRACT-TOOL-001 and implement `GetFuelingInfoTool` on the pinned Koog surface — the spec §4 SELECT chain across the four databases aggregated per CONTRACT-TOOL-001-OUT (spec §3).

## Acceptance Criteria
- [ ] `src/main/resources/tools/get_fueling_info.json` is byte-identical to the JSON body of CONTRACT-TOOL-001 (spec §3); `diff` against the spec content is empty.
- [ ] `GetFuelingInfoTool` implements `SimpleTool<GetFuelingInfoArgs>` with the `@Serializable` args class and `@property:LLMDescription("The fueling identifier to look up.") val fueling_id: String` per the pinned surface in spec §3.
- [ ] The handler executes the spec §4 chain in order: fuelings by `fueling_id` (`ORDER BY created_at DESC LIMIT 1`), gas_stations by `gas_station_id`, payments by `order_id = vendor_fueling_order_id` (D-14, `ORDER BY created_at DESC LIMIT 100`), vendors tables with `LIMIT 100` and explicit ordering (`fueling_events` by `event_offset ASC`).
- [ ] Against the seeded container from T05, executing the tool for `F-10001` returns the six keys of CONTRACT-TOOL-001-OUT with values matching the spec example (integration test asserts the seeded rows, including both payments and both events).
- [ ] Timestamp normalization (D-15): epoch-ms columns and `gas_stations.updated_at` are emitted as ISO-8601 UTC strings, text date columns (`vendor_transaction_date`, `date_create`) pass through verbatim, jsonb columns are emitted as their JSON text, and `null` stays `null` (test asserts on seeded rows).
- [ ] Unknown `fueling_id` returns `{"fueling": null, "gas_station": null, "payments": [], "fueling_orders": [], "fueling_events": [], "vendor_fueling_orders": []}` (spec §4 rule 4; test).
- [ ] Tool-set fail-fast: the loader that locates `resources/tools/get_fueling_info.json` fails with a clear message naming the missing file when it is absent (unit test); boot wiring lands in T04 (design §6).
- [ ] `./gradlew build ktlintCheck detekt` completes with 0 errors.
