- [ ] Provider switching: the active model id reaches the `provider` field (`local` default per D-10, `remote` after switching) — the existing App send-flow test stays green.
- [ ] No streaming/polling primitives: `grep -rE "EventSource|WebSocket|setInterval" src` returns nothing (D-7).
- [ ] `pnpm build && pnpm lint && pnpm test` all exit 0.
