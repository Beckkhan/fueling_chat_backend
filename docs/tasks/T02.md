# T02 - Backend logging & fail-fast config

**Status:** `todo`
**Owner:** `backend-coder`
**Dependencies:** `[T01]`
**Contracts:** `[CONTRACT-LOG-001]`

## Description
Implement the typed `AppConfig` read from `.env` with fail-fast on missing/empty required keys, and logback with mask-before-write so secrets never reach logs — per design §2 and the fail-fast guarantees of design §6 / D-2.

## Acceptance Criteria
- [ ] `AppConfig` reads every key documented in the tracked backend `.env.example`; on a missing or empty required key the app aborts at startup with a non-zero exit and a clear message naming the key (design §6). Verified by removing a key from `.env`, then restoring it.
- [ ] `logback.xml` sits in `src/main/resources/` and is the SLF4J configuration for the app.
- [ ] Mask rules cover `DEEPSEEK_API_KEY`, `DB_PASSWORD`, `Authorization` (incl. Bearer), and JSON fields `api_key` / `password` / `secret` / `token` (design §2); a log line containing a fake secret shows the masked form, never the plaintext.
- [ ] `./gradlew build` completes with 0 errors.

## Artifact
- `src/main/resources/logback.xml`
- `src/main/kotlin/.../config/AppConfig.kt`
